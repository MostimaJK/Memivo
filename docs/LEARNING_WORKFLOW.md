# Memivo 标注、数据集与训练

## 从图像到自定义模型

1. 在功能中心安装视觉 AI 引擎；模型权重另行准备。
2. 进入“标注与数据集”，新建目标检测或实例分割数据集。导入图片或文件夹；程序复制并校正方向，不修改原图，并按归一化后的像素内容去重。
3. 创建类别。检测可画矩形框，分割画多边形。选择编辑模式后可移动目标、拖动框角点或轮廓顶点；按删除按钮移除选中项。多边形用 Enter 或双击完成，Esc 取消。
4. 保存草稿，再人工确认标注。没有目标时明确勾选负样本。未标注图像不视为负样本。切换图片会先保存草稿；切换工作区保留当前草稿，关闭前仍应保存。
5. 可运行 YOLO 预标注并导入检测框和类别，或以框/概念提示运行 SAM3，再将外轮廓加入当前类别。选中的矩形框会被 SAM3 轮廓替换。候选均需人工审核；分离轮廓、遮挡和孔洞尤其需要检查。
6. 为连拍、同场景图片设置相同场景组，再自动按组划分约 70/20/10，或手工修改当前组的 train/val/test。默认每张图是独立组，程序不会自动理解哪些图片来自同一场景。
7. 固定数据集版本：只收录已确认图片，要求三个划分均有图片、每个类别在训练集中存在。分割版本必须使用轮廓标注，矩形框不会伪装成精确掩码。版本包含标准 YOLO 标签、data.yaml、图像、版本元数据与文件校验值。可导出供其他工具使用。
8. 进入训练工作台，选择固定版本和任务匹配的本地 `.pt` 权重，设置轮数、尺寸、batch、设备后开始。CPU 验收配置为 320、batch 2；真实数据按显存和验证结果调整。
9. 查看真实训练指标与曲线。停止会终止子进程；已有完整 last.pt 的中断任务可恢复，首轮尚未写出检查点时不能恢复。失败诊断在日志中保留。
10. 训练结束后主动执行独立测试集评估。展示 YOLO 检测/分割指标，以及置信阈值 0.25、IoU 0.7 下的每图总目标数 MAE。MAE 是框数误差，不是跨图像独立人数或每个类别的完整统计指标。
11. 点击“用于检测与计数”，将该实验 best.pt 设为当前 YOLO 模型；或导出 best.pt 与实验、类别、版本记录。

## 数据位置与一致性

源码启动默认使用 `.segmentflow/`。EXE 默认使用 `%LOCALAPPDATA%/Memivo/data/`；可选引擎、数据集和训练记录都在该状态目录内。外置照片与权重不随引擎卸载删除。

数据集与原人物相册独立。类别 ID 稳定，导出时映射成连续 YOLO ID。保存标签校验版本号，避免旧页面覆盖新标注。训练前检查版本的文件校验值；后续改标签不影响已固定的版本。训练中不允许修改数据集或安装/卸载引擎，同一时间执行一个模型任务。

固定版本会复制图像，占用额外磁盘；首版不做共享存储或自动清理历史实验。模型文件、数据集与训练结果不打进 EXE 发布包。跨电脑测试建议重新导入图片并配置权重；首版不自动修复从其他电脑复制来的绝对路径记录。

## 本版验收范围

- 已在 Windows/Python 3.12 实际安装 CPU 视觉引擎，执行环境检查。
- 实际完成生成的合成数据上的 YOLO 检测训练、分割训练、独立测试评估、取消/断点恢复、应用权重及再次检测。
- 合成数据只用于检查程序流程；少量轮次与零/低检测指标不代表真实照片上的识别精度。
- 数据管理、坐标、负样本、去重、场景划分、快照校验等有自动测试；GPU 训练、真实 SAM3 权重及人脸模型仍需在目标设备验收。

接口依据：[YOLO 训练](https://docs.ultralytics.com/modes/train/)、[训练回调](https://docs.ultralytics.com/usage/callbacks/)、[分割标签](https://docs.ultralytics.com/datasets/segment/)。
