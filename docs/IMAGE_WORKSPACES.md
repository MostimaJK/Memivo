# 圖片畫布、分割結果與匯出

## 拖放匯入

圖庫、人物相簿、偵測及分割工作區支援拖入一張或多張圖片。參考照片及資料集匯入彈窗也提供拖放區與檔案選擇入口。資料集工作區需先建立或選取資料集，匯入前會保存目前的標註草稿。

- 支援 JPG、JPEG、PNG、WebP、BMP、TIF、TIFF；每張須有內容且不超過 64 MB。拖放資料夾尚未支援，請使用既有資料夾路徑匯入。
- 檔案經過目前電腦的 `127.0.0.1` 服務傳入應用資料目錄 `imports/<批次 ID>/`，不傳到外部伺服器；原始檔案保留。
- 拖入一般工作區會追加至目前圖庫，依檔案內容雜湊去重，保留既有人工審核結果，並選取第一張新增圖片。參考照拖放會填入參考照路徑，仍須輸入姓名並儲存。
- 使用舊的檔案／資料夾「路徑匯入」會開啟該來源的獨立專案；與拖放追加的行為不同。
- 複製的圖片會佔用本機空間，解除安裝 AI 引擎不會刪除這些圖片。

## 畫布操作

分割及偵測工作臺開啟圖像時，會依可用畫布的寬、高完整適配。切換照片會重設視角；切換同一張照片的結果視圖會保留視角。

- 在畫布上滾動滑鼠滾輪：以游標所在位置為中心縮放，不捲動頁面。
- 偵測頁或分割頁「拖動」模式：拖曳移動圖片。點選偵測框會選取對應目標；也可以中鍵拖曳平移。
- 點／框標記模式：左鍵繼續標記，中鍵拖曳，或在畫布聚焦後按住空白鍵拖曳來平移。
- 分割標記：右鍵刪除附近的點或游標所在的框；空白處右鍵不刪除遠處標記。`Ctrl+Z` 復原、`Ctrl+Shift+Z`／`Ctrl+Y` 重做，`Esc` 取消正在繪製的框。標註編輯器支援右鍵刪除目標，繪製多邊形時右鍵撤回上一頂點；Delete 刪除選取目標。
- 「重設視角」或畫布聚焦後按 `0`：恢復完整適配並居中。`+`／`-` 可縮放。
- 縮放百分比表示圖像原始像素相對於畫布 CSS 像素的比例；完整適配不一定是 100%。

分割標記與偵測框跟隨圖像一起移動及縮放，座標仍以 EXIF 方向校正後的原始圖像為準。主畫布載入完整解析度圖像；大量超高解析度照片可能增加記憶體需求。

## 分割後會產生什麼

成功後自動保存：

| 檔案 | 說明 |
| --- | --- |
| mask.png | 原圖尺寸、灰階黑白遮罩，前景為 255，背景為 0 |
| cutout.png | 原圖尺寸、透明背景 RGBA 去背圖 |
| crop.png | 裁切至目標邊界的透明去背圖 |
| overlay.png | 原圖與彩色遮罩的疊加預覽 |
| instance-N*.png | 每個目標的獨立遮罩、原圖尺寸去背圖及裁切圖 |

每次成功執行均建立獨立結果目錄。預設位置為：

- 原始碼版：專案根目錄 `.segmentflow/segments/<執行 ID>/`。
- Windows EXE：`%LOCALAPPDATA%/Memivo/data/segments/<執行 ID>/`。
- 自訂 MEMIVO_HOME 時依該應用資料目錄存放；介面顯示的完整目錄為準。

右側結果卡顯示成功與目標數量、儲存目錄及匯出按鈕。桌面版可按「開啟結果資料夾」；瀏覽器測試模式僅顯示路徑，不開啟系統檔案管理器。

畫布上方「原圖 / Result」按鈕會切換文字及顏色。另有黑白遮罩及透明去背圖快捷按鈕。預設疊加強度為 80%，彩色遮罩更深；不改變黑白遮罩的 0／255 像素。疊加透明度只在疊加模式生效；透明圖使用棋盤背景。

## 自動保存與匯出不同

自動保存寫入應用資料目錄，原始照片不會被修改。「匯出去背圖或遮罩」則會將選定結果另存至你選擇的目錄，完成後顯示完整檔案路徑。

可以選擇全部目標合併，或單一目標。透明圖可選裁切／原圖尺寸；黑白遮罩固定保留原圖尺寸，方便後續標註與演算法處理。

無目標、取消或錯誤時，不覆寫上一個成功結果。失敗會顯示錯誤提示；舊結果仍可檢視，不代表新的嘗試已成功。目前會話中的結果視圖不會在重啟後自動恢復，已保存的 PNG 仍保留在結果目錄。

## 偵測與計數

成功後在圖片上顯示框、類別、編號與信心分數，畫布下方顯示總數與分類計數。可以切換原圖／偵測結果，或依類別篩選並選取目標送至 SAM3。

「匯出偵測 JSON」會將框、類別、分數、閾值與計數另存到所選目錄。未檢出目標會顯示 0 與調整提示；模型沒有學過的物品需要相應權重。

## 驗證範圍

畫布縮放、平移、視角重設、結果切換及匯出使用隔離的合成圖像／模型替身驗證，不作為 SAM3／YOLO 精度或 RTX 5070 Ti 實機推理的證明。


## YOLO 速度與引擎重用

YOLO 現在使用獨立常駐程序，連續偵測同一權重／裝置時會重用模型，不會每張圖片重新載入 PyTorch、權重及 CUDA。更換權重（包含修改時間或大小）或裝置時重載；取消、失敗後丟棄該程序，下次乾淨重啟。閒置 5 分鐘、開始其他 AI 工作、卸載引擎或關閉程式時釋放，避免長期佔用 GPU 記憶體。首次偵測仍包含冷啟動與預熱。

結果區的效能卡顯示實際推論裝置／GPU 名稱、是否重用模型、模型載入、圖像讀取、偵測處理及其中模型推論耗時。「本次處理」包含引擎往返及後端處理，不包含瀏覽器繪製及狀態輪詢延遲；「模型推論」來自 Ultralytics 的 `Results.speed`，不能與整個桌面操作耗時混用。匯出 JSON 會保留 `performance` 詳細資訊與 PyTorch / CUDA 版本。

設定頁底部的套件標記僅代表 **主介面環境**。AI 引擎刻意獨立安裝；主介面顯示 ultralytics 不存在，不代表功能中心的視覺引擎缺少此套件。能正常產生 YOLO 偵測結果即已調用 Ultralytics；新增效能卡可確認實際執行裝置。

2026-10-17 本機檢驗：官方 YOLO26n、CPU、2400×1600 PNG，同一圖片；舊的逐張啟動流程 3 次中位數 4020 ms，改造後暖啟動 3 次中位數 75 ms，首次常駐偵測約 3207 ms。這是固定輸入的小型實驗，非精度評估、非 YOLO26l／RTX 5070 Ti 的 GPU 基準，不能推論所有圖片皆有相同速度。預設 .pt 推論精度與解析度不變，尚未導出 TensorRT 或啟用 FP16。
