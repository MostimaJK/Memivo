# 圖片畫布、分割結果與匯出

## 畫布操作

分割及偵測工作臺開啟圖像時，會依可用畫布的寬、高完整適配。切換照片會重設視角；切換同一張照片的結果視圖會保留視角。

- 在畫布上滾動滑鼠滾輪：以游標所在位置為中心縮放，不捲動頁面。
- 偵測頁或分割頁「平移」模式：拖曳移動圖片。點選偵測框會選取對應目標；也可以中鍵拖曳平移。
- 點／框標記模式：左鍵繼續標記，中鍵拖曳，或在畫布聚焦後按住空白鍵拖曳來平移。
- 「重設視角」或畫布聚焦後按 `0`：恢復完整適配並居中。`+`／`-` 可縮放。
- 縮放百分比表示圖像原始像素相對於畫布 CSS 像素的比例；完整適配不一定是 100%。

分割標記與偵測框跟隨圖像一起移動及縮放，座標仍以 EXIF 方向校正後的原始圖像為準。主畫布載入完整解析度圖像；大量超高解析度照片可能增加記憶體需求。

## 分割後會產生什麼

成功後自動保存：

| 檔案 | 說明 |
| --- | --- |
| mask.png | 原圖尺寸、灰階黑白遮罩，前景為 255，背景為 0 |
| cutout.png | 原圖尺寸、透明背景 RGBA 去背圖 |
| crop.png | 裁切至目標邊界的透明去背圖 |
| overlay.png | 原圖與彩色遮罩的疊加預覽 |
| instance-N*.png | 每個目標的獨立遮罩、原圖尺寸去背圖及裁切圖 |

每次成功執行均建立獨立結果目錄。預設位置為：

- 原始碼版：專案根目錄 `.segmentflow/segments/<執行 ID>/`。
- Windows EXE：`%LOCALAPPDATA%/Memivo/data/segments/<執行 ID>/`。
- 自訂 MEMIVO_HOME 時依該應用資料目錄存放；介面顯示的完整目錄為準。

右側結果卡顯示成功與目標數量、儲存目錄及匯出按鈕。桌面版可按「開啟結果資料夾」；瀏覽器測試模式僅顯示路徑，不開啟系統檔案管理器。

畫布上方可切換原圖、疊加結果、黑白遮罩及透明去背圖。疊加透明度只在疊加模式生效；透明圖使用棋盤背景。

## 自動保存與匯出不同

自動保存寫入應用資料目錄，原始照片不會被修改。「匯出去背圖或遮罩」則會將選定結果另存至你選擇的目錄，完成後顯示完整檔案路徑。

可以選擇全部目標合併，或單一目標。透明圖可選裁切／原圖尺寸；黑白遮罩固定保留原圖尺寸，方便後續標註與演算法處理。

無目標、取消或錯誤時，不覆寫上一個成功結果。失敗會顯示錯誤提示；舊結果仍可檢視，不代表新的嘗試已成功。目前會話中的結果視圖不會在重啟後自動恢復，已保存的 PNG 仍保留在結果目錄。

## 偵測與計數

成功後在圖片上顯示框、類別、編號與信心分數，畫布下方顯示總數與分類計數。可以切換原圖／偵測結果，或依類別篩選並選取目標送至 SAM3。

「匯出偵測 JSON」會將框、類別、分數、閾值與計數另存到所選目錄。未檢出目標會顯示 0 與調整提示；模型沒有學過的物品需要相應權重。

## 驗證範圍

畫布縮放、平移、視角重設、結果切換及匯出使用隔離的合成圖像／模型替身驗證，不作為 SAM3／YOLO 精度或 RTX 5070 Ti 實機推理的證明。
