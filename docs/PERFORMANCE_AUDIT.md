# Memivo 效能與記憶體優化檢查

檢查日期：2026-10-17。基於 v0.3.11 原始碼；本次先修正人物相簿空狀態，以下為待實作的效能路線圖，**不是已完成的加速功能或 RTX 5070 Ti 測速結果**。

v0.3.13 已完成第一批保持輸出一致的處理優化，詳見 [實作與量測結果](PERFORMANCE_RESULTS.md)。以下表格保留原始基線發現；特徵快取、混合精度、批次及顯存政策仍待驗證。

## 結論與已有機制

目前不應直接換小模型或降低圖片解析度來掩蓋開銷。先量測完整處理鏈，優先消除重複編碼、同步匯出與狀態傳輸；再評估混合精度及 TensorRT。

已存在：YOLO / SAM3 常駐工作程序、模型版本鍵、取消與逾時管理、非手動保留模型的 300 秒閒置釋放；切換功能會釋放另一個未固定的模型。SAM3 文字模式已快取同圖特徵，人物整理已有持久化特徵快取與模型／前處理指紋。這些不是待補的「每張重新載入」問題。

證據：`desktop/inference_worker.py`、`desktop/runtimes.py::resident_job`、`scripts/detection_worker.py`、`sam_backend.py::process_text_prompt`、`album/service.py::run_project`。

### YOLO 的補充判斷

`desktop/detection.py::YOLOBackend.predict` 目前分別將座標、類別及分數轉 CPU；可測試一次搬移，但這類小張量不應在未量測時歸因為數秒延遲。檢測／計數可載入 segment 權重，若只需要框，優先使用 detect 權重以避免不必要的分割工作。批次增加吞吐量與單張互動加速是不同目標。

FP16、輸入尺寸、較小 YOLO、TensorRT、INT8 都應獨立比較。INT8 需要有代表性的校正／驗證資料；小臉、細物件與遮擋場景不可只比較 FPS。現有環境 API 可能與最新文件不同，應從實際安裝版本取得有效參數，不硬套網路範例。

### 顯存與 RAM 必須分開

現有進度條顯示整張 GPU 的使用量，包含桌面與其他程式，不等於 Memivo 本身。建議每個工作程序補記 GPU 名稱／PID、PyTorch allocated、reserved、peak allocated、peak reserved；ORT 另記 provider 與 session 策略，不將 PyTorch 指標當作 ORT 的完整使用量。

6000×4000 圖片的 RGB 約 72 MB、RGBA 約 96 MB；一張 bool 遮罩約 24 MB，10 張即 240 MB，尚未計算副本。這是資料大小推算，不是實測峰值。全尺寸逐實例輸出、遮罩傳輸與疊色可能先消耗大量 CPU RAM。

`empty_cache()` 只釋放未使用的快取區塊，不能釋放仍被引用的模型。不能每張圖片後呼叫，以免破壞重用；現有程式主要在更換模型／模式時使用。ORT 的 `gpu_mem_limit` 只約束相關 arena，不是整個程式／整張卡的硬上限。

## 建議執行的三個階段

1. **基線與低風險開銷**：統一計時與峰值記錄；去除確定多餘的 CPU 複製；整理結果保存與 UI 更新的時間線。保持輸出內容與現有自動保存行為。
2. **互動與顯存**：驗證 SAM3 幾何圖像特徵重用、分階段輸出、模型顯存預算；更新輪詢與有界圖片快取。
3. **推理部署**：在 5070 Ti 比較 FP32 / FP16 / TensorRT；人臉動態 batch，之後才評估量化與模型訓練層優化。

## 可重現的驗收方法

- 固定模型 hash、軟體版本、驅動、裝置、解析度、精度、閾值、提示及照片清單。記錄其他 GPU 使用與可用顯存；不要自動關閉使用者程式。
- 測 1、3、10 個目標，低／高解析度、同圖反覆改提示、連續切圖；加上兩模型固定、單模型、CPU、取消／失敗恢復情境。
- 冷啟動分開記錄至少 3 次；每組先做準備執行，再量測至少 30 次暖態操作，報 p50 / p95、峰值 RAM、各程序顯存峰值、整卡使用量、輸出 bytes 與檔案數。小樣本尾延遲需註明不確定性。
- 相同演算法的搬移／快取改動檢查 bbox、分數、mask 與匯出像素；混合精度及部署後端改動用獨立標註集評估 mAP、mask IoU、小目標召回及計數誤差，再決定可接受差異。
- GPU 階段用 CUDA event 或明確同步的基準模式；一般日誌保持低開銷。端到端時間從按下執行到結果真正可見，不能以模型 `inference ms` 代替。
- 記錄相同圖片重複執行的 encoder 次數、模型是否重用、快取是否命中及實際執行裝置。未驗證裝置不顯示為 GPU 成功。
- 不預填加速百分比；先取得基線與修改後同條件數據，再寫履歷／README 指標。
