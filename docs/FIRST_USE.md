# 第一次使用 Memivo（First use）

本指南適用於 Windows x64 預覽版。建議先完成一次 CPU 偵測，確認安裝、模型選擇與匯入皆正常，再設定 SAM3 或人物識別。

## 1. 選擇啟動方式

| 方式 | 適合對象 | 需要準備 |
| --- | --- | --- |
| Release ZIP → `Memivo.exe` | 想直接使用或在另一台電腦測試 | Python 3.12 x64、WebView2、首次安裝時的網路 |
| 原始碼 → `start_memivo.bat` | 想修改程式或參與開發 | Python 3.10–3.12、Node.js LTS、WebView2 |

官方安裝來源：[Python](https://www.python.org/downloads/windows/) · [WebView2](https://developer.microsoft.com/microsoft-edge/webview2/) · [Node.js](https://nodejs.org/)。

EXE 仍使用外部 Python，不是完整離線安裝包。ZIP 必須全部解壓縮，請不要只取出 EXE，也不要將應用程式放在無寫入權限的系統目錄。

## 2. 首次開啟

1. 按兩下 `Memivo.exe` 或 `start_memivo.bat`。
2. 等待介面環境準備完成。首次需要下載套件；後續已安裝且來源未變時會重用環境與建構結果。
3. 如需繁體介面，開啟右上角設定，將 Language 改為「繁體中文」，再儲存。
4. 可以先瀏覽介面、匯入照片及建立標註資料集；這些操作不需要模型權重。

正常情況下，安裝目錄會有 `app/` 與 `model/`；資料與界面環境在 `%LOCALAPPDATA%/Memivo/`。原始碼模式的狀態目錄為專案內的 `.segmentflow/`。兩種啟動方式使用不同的預設狀態位置，不會自動搬移彼此的相簿或訓練紀錄。

## 3. 安裝需要的引擎

開啟「功能中心」，等待硬體偵測完成。

| 目標 | 引擎 | 還需要的權重 |
| --- | --- | --- |
| 手動標註、管理資料集 | 不需要 AI 引擎 | 不需要 |
| YOLO 偵測、計數與訓練 | 視覺 AI 引擎 | 對應的偵測或分割 `.pt` |
| SAM3 提示分割與去背 | 視覺 AI 引擎 | `sam3.pt` |
| 人物識別與相簿整理 | 人物識別引擎 | SCRFD 偵測 ONNX ＋ LVFace／ArcFace 識別 ONNX |

首次建議選 CPU，先驗證工作流程。NVIDIA 方案需要相容的顯示卡與驅動；自動偵測的推薦不等於已在你的電腦完成實際模型驗證。人臉引擎支援 CPU 與 NVIDIA CUDA 12.8；相容顯示卡可選自動或 NVIDIA 方案。安裝驗證成功後，請在設定將執行裝置改為 NVIDIA CUDA；既有 CPU 引擎須先卸載再安裝 GPU 方案。詳見 [引擎與 GPU 切換指南](OPTIONAL_ENGINES.md)。

視覺引擎估計需 CPU 約 1–3 GB、NVIDIA 約 4–10 GB 磁碟空間，實際依套件版本而異，另外還需模型、照片與訓練輸出空間。程式不會自動安裝系統 Python、顯示卡驅動或完整 CUDA Toolkit。InsightFace 在部分 Windows 環境需要既有的 C++ 建構工具；失敗時請保留診斷紀錄。

## 4. 先完成一次物件偵測

1. 在功能中心的「官方預訓練模型」選擇 **YOLO11 → 目標偵測 → yolo11n.pt**。這是較輕量的入門選項，不代表所有任務的最優模型。
2. 查看官方條款後開始下載，等待檔案大小與 SHA-256 校驗完成。
3. 開啟設定，按「掃描模型」，選擇該權重，將執行裝置設為 CPU，再儲存。唯一候選可能已自動選取；多個候選時請明確選擇。
4. 匯入少量照片，在「偵測與計數」選擇照片並執行偵測。
5. 查看框與類別計數，必要時調整信心閾值，或匯出 JSON。

官方 YOLO 預訓練類別不等於任意物品皆可辨識。若要辨識特定筆款、零件或自訂商品，需要符合任務的權重，通常要先標註並訓練。計數是目前圖像的偵測目標數，不是跨照片去重後的獨立人數。

## 5. 改用其他功能

### 從合照整理人物相簿

準備符合條款的 SCRFD 偵測 ONNX 與 LVFace／ArcFace 識別 ONNX，分別放入 `model/face/detector/`、`model/face/recognition/`。在設定掃描、選擇並儲存後，匯入照片、登記朋友及參考照，再開始整理。檢閱不確定的候選後匯出人物相簿；同一張合照可複製到多個人的匯出相簿，原圖不移動。

官方部分人臉預訓練權重僅授權非商業研究；不能把「非商業研究」直接等同於所有免費個人用途。請先核對所選權重條款，正式商業化尤其需要另外確認。詳見 [授權選型與依賴](LICENSING_OPTIONS.md)。

### 從照片切出物品

在 [SAM3 官方頁面](https://huggingface.co/facebook/sam3)自行申請存取並下載 `sam3.pt`，放入 `model/sam3/`。設定中選擇權重，於分割工作臺使用文字、正負點或框提示，檢查結果後匯出透明 PNG。支援個別實例及合併匯出；本專案尚未以真實 SAM3 權重完成目標設備驗收。

### 訓練自己的物件模型

新增偵測或實例分割資料集 → 匯入照片與新增類別 → 畫框／多邊形或使用 AI 候選 → 人工確認標註與負樣本 → 依場景群組劃分 train/val/test → 建立固定版本 → 選擇任務匹配的 YOLO 權重訓練 → 評估獨立測試集 → 套用或匯出模型。

AI 候選需要人工確認；沒有標註不等於負樣本。同一場景或連拍請放在同一群組，避免跨訓練與測試集洩漏。分割訓練需要多邊形輪廓，矩形框不會自動變成精確遮罩。詳見 [完整標註與訓練流程](LEARNING_WORKFLOW.md)。

## 常見問題

| 狀況 | 檢查方向 |
| --- | --- |
| EXE 找不到 Python | 安裝 Python 3.12 x64，或以 `MEMIVO_PYTHON` 指向該解譯器；閱讀 `%LOCALAPPDATA%/Memivo/launcher.log` |
| 介面無法開啟 | 檢查完整 ZIP 與 WebView2，閱讀啟動紀錄；可執行 `Memivo.exe --check` 檢查發布內容 |
| 權重未出現在下拉選單 | 檢查用途子目錄、副檔名、檔案是否為空，排除未下載完的 `.part`；重新掃描 |
| 引擎已安裝但模型無法執行 | 引擎與權重是不同項目；檢查架構、裝置、剩餘記憶體及診斷紀錄 |
| CUDA／顯示記憶體錯誤 | 先改 CPU，或降低訓練尺寸與批次大小，再於目標設備檢查驅動與引擎 |
| 人臉引擎無法安裝 | 檢查功能中心紀錄；可能需要 Windows C++ 建構工具，不要從未知來源安裝 wheel |
| 停止後不能恢復訓練 | 必須已有完整 `last.pt`；首輪尚未寫出檢查點時，請重新開始 |
| 原始碼啟動要求 Node.js | 原始碼需要建構前端；Release ZIP 已內附建構結果，因此不需要 Node.js |

其他環境細節見 [桌面說明](SPECTRUM_DESKTOP.md) 與 [可選引擎](OPTIONAL_ENGINES.md)。

## InsightFace 初次配置

需要人物整理时，先看 [InsightFace 下载与文件说明](INSIGHTFACE_MODELS.md)，按表格取出检测及识别两个 ONNX 文件，扫描后在设置中确认；不要把关键点或年龄性别模型当作识别模型。
