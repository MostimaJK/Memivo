# 緊湊工作區設計紀錄 · v0.3.11

使用者回饋：顯存框與頁面說明占用太多高度；希望大標題、顯存同一列，減少重複按鈕並保留關鍵功能。

| 原有問題 | 採用決策 |
| --- | --- |
| 副標題和獨立設備框壓縮圖片區 | 取消頁面副標題，顯存移至標題行，裝置證據改為可展開標籤 |
| 偵測／分割有重複匯入入口 | 工具列保留一個單張匯入；空狀態和拖放保留 |
| 固定高度公式與實際內容高度不符 | 編輯頁採剩餘高度 flex 佈局，側欄獨立捲動 |
| 未使用的提示欄、說明卡長期占位 | 依模式及結果顯示欄位，次要資訊預設收起 |
| 訓練權重有多個重複入口 | 合併為模型庫下拉選單與外部檔案按鈕 |

沿用已認可的 Adobe Spectrum 2、圓角工作面、字型及語意顏色，不改變導航、模型推論、資料格式或授權。這是密度與資訊層級調整，不是重新選擇 GUI 架構。

主要改動：main、ExecutionStatus、GpuMemory、DetectionWorkspace、DatasetWorkspace、TrainingWorkspace、FeatureCenter、ModelCenter，以及對應樣式與詞條。

檢查：1280×720 瀏覽器中，標題區約 70 CSS px；分割畫布約 289 CSS px，標題中無重複單張匯入按鈕，頁面無橫向溢出。中英文標題及圖庫操作列、分割文字模式、保存目錄、實際裝置詳情、模型選擇已人工操作。示例為合成圖／明確模型替身；顯存為真實本機 NVIDIA 取樣。未宣稱原生多螢幕或全部 DPI 組合已驗收。
